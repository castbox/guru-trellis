# Bounded standalone wording review

Use standalone_wording_review only for an explicit read-only Issue or draft
wording request. Read the selected complete current title/body, necessary source
clauses and the shared clear-technical-writing.md. Apply the original Issue
content method to meaning, conditions and obligation strength within this bounded
request. Do not require Discovery receipts, Task binding, Delivery selection,
complete Intake or start readiness. The script validates the current selected
object; the Agent owns findings and conclusion.

Report each real ambiguity or lost meaning with its location, impact and original
revision owner. Clear advice, defaults, quotations, history and literals are valid
under their actual source role and need no lexical classification. Do not block
because a word occurs. If a necessary object or source is unavailable, explain
that concrete gap and return blocked. Return reviewed with the actual readable
conclusion and concrete findings when this requested assessment is complete.
Neither result enters Readiness or the Task graph.

Invoke scripts/invoke.sh with the current shared semantic-owner envelope, no
transition, profile=standalone_wording_review and mode=standalone. For an Issue,
owner_context.change_request is the actually captured kind/repo/number/title/body/
updated_at; the validator rereads it. The draft's selected title/body are in public
input. Keep all content call-local. This request never grants repair, comment,
publication or file-write authority; actual revision follows its original owner.
