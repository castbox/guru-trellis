# Guru Verify Extension Installation

Use after a reviewed extension change is available at a remote ref, or invoke
directly with an explicit standalone repository intent. Read
`references/contract.md`, validate the selected public input, let the AI own
applicability, capability selection, adequacy, findings, and route, then call
the package executor, recorder, checker, and public wrapper through the shared
dispatcher.

Changed-path matches, command exit code zero, empty findings, production eval,
and checker success never create a semantic `verified` result. A taskless
standalone invocation is session-only and cannot emit `return_to_task_work`.

Emit exactly one declared typed exit. Missing, stale, ambiguous, multiple,
unmapped, or checker-failed evidence fails closed.
