# Issue Readiness supplement

Consume the actual supplement output from original Readiness. Add only
profile=issue_readiness_supplement and rename exit_id to source_exit. Preserve
mode, Issue, base_source (kind/selected_ref/commit), continuation_id and gap.
No current context_current/clarity_current/wording_current transition is required.
Read current authority and still-applicable evidence, then perform this owner's
original full applicable method and AI gate. The gap states the review purpose;
it does not permit omission of necessary facts or complete-body consistency.

The local issue-review-owner-1.0 result binds public_input exactly and contains
actual typed_exit, result_summary, source_refs and ai_review_gate. Its summary
states what this owner established and its limits. `supplemented` carries only
identity, summary and source refs back to Readiness issue_review_return. It
neither chooses ready nor automatically starts the default next owner. A genuine
blocked judgment uses the original blocked stop. No review history, authorization
record or cross-Skill digest is added. Readiness rereads authority and judges what
still needs work. A local source/Issue/continuation mismatch stops at the original
producer; do not change the identity to fit a different result.

The local owner result additionally contains the independent issue-clarification-1.0
result and source_selection. Use its real Issue target, scope/source judgments,
question convergence and original source_actions definitions. This local shape
requires no duplicate snapshot, upstream disposition token or full-chain receipt. Record
with --mode <mode> --input -; check with --input -; invoke with the independent
public_input/owner_result envelope. The wrapper validates the unchanged current
Issue/source and the actual Clarify result. A current clear becomes supplemented.

If facts are missing, the original needs_context result carries the Issue/source/
continuation/gap into Discovery context_request and preserves return_identity.
The actual context_ready returns to this same local profile with context_result
and source_refs before clarification resumes. Do not rerun unrelated Wording.
A real target change returns to original full Intake; it is not a successful
same-Issue supplement.

Read [the shared review comment rule](issue-review-comment.md) before comment
writing. An active review request with explicit publish/update scope uses original
source_actions POST/PATCH and live Issue/comment GET readback. Pure read-only
review writes no comment. Local or partial review never claims full readiness.
Successful body/comment mutation preserves its actual refresh_context private
result, then returns supplemented to Readiness after the live reread; it does
not force Sync when the source baseline is still applicable. Unknown result first
recovers the same original action, never blindly reposts a comment.
