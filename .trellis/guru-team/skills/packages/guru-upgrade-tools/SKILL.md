not the old target dispatcher. Read [the contract](references/contract.md) and
the selected public profile in `interface.json`. The source runtime executes;
`--root` is invocation context only. Discovery copies are not self-contained.

Use `scripts/preview.sh` for facts, `scripts/prepare.sh` once to freeze the
reviewed public tools plan, and `scripts/invoke.sh` for execution or same-owner
recovery. Follow forward behavior → AI Review Gate → conditional dialogue
confirmation → executor/validator → exactly one typed exit. Scripts never
judge sufficiency, route intent or approval. Missing API, stale source,
conflict, unknown exit or incomplete native validation stops.

Read `.trellis/spec/workflow/workflow-contract.md#interaction-budget` before
asking for a real choice or write confirmation, and
`.trellis/spec/workflow/companion-scripts.md#intermediate-command-stdout-10`
for intermediate receipts. Do not use full installation migration as fallback.
