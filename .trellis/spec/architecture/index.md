# Architecture Baseline Specs

## Pre-Development Checklist

1. 读 [baseline-usage.md](./baseline-usage.md)。
2. 从 `docs/architecture/README.md` 进入 FOUNDATION 与 CURRENT。

4. 通过 RDT traceability 检查 requirement/design/test inheritance。

本目录只提供 locator、读取顺序、route 与 freshness，不复制 Architecture authority 正文。
