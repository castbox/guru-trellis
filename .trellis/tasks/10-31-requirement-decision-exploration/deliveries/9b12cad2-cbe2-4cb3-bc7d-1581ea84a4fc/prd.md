# D1 需求歧义探索与分级确认

## 1. 整体来源与术语

整体来源为 `../../prd.md` 第1至8节与公共 accepted_scope；本批 scope_ref 选择 DEC-AC1 至 DEC-AC6，planning_root 为本目录。来源角色、需求选择、纯实现细节与轻度问题定义沿整体第1节。当前用户需求是要求，兄弟模板只是方法参考，不将其所有风险矩阵和记录机制引入本仓库。

## 2. 整体与本批目标、非目标

本批完整实现 DEC-R1 至 DEC-R8：让原 Clarify 与 Author 主动发现歧义，并把所有未定需求交用户决定；轻度推荐清单降低交互成本，重大取舍说明选项，常规实现由 AI 完成。已有正确行为不因设计图省略而删除。

不新增平行 Skill、审批链、决策台账、公共字段或脚本语义判断；不修改 upstream-owned brainstorm、业务代码或业务项目安装。不包含 GitHub 写入、提交和发布。需求确认与原规划激活、外部副作用边界仍然独立。

## 3. 本批起点、前序结果、依赖与剩余责任

首次 D1，无前序交付。开发起点为 main 的 a4feadd99683e006580ef16b078c44e3ad3648a7。当前已具有证据先行、单问题循环、逐项问题关闭及 Author 技术细化职责，缺少轻度推荐清单的明确适用规则、具体问题发现方法和一致的技术取舍边界。

本批覆盖全部整体验收，无计划延期切片。完成需实际规则、示例、验证和安装投影共同支撑；本地测试不等于完整 Task Completion 或业务项目已升级。真实交互验证依赖可用 native Agent 执行入口；不可用时报告具体缺口，不用预写答复伪装执行。

## 4. 本批调用方、场景与流程

| 场景 | 调用方、前置与动作 | 行为与可观察结果 |
| --- | --- | --- |
| DEC-S1 | Clarify 收到简略请求 | 调查事实、受影响旧行为与具体例子，区别事实未知和需求选择 |
| DEC-S2 | 发现同阶段互不依赖的轻度歧义 | 提供简短推荐清单和影响；用户可以一次接受或逐项修正 |
| DEC-S3 | 存在无法由既定约束选定的重大取舍 | 研究可行选项并说明推荐、行为、成本和风险，不要求用户写实现 |
| DEC-S4 | 需求完整且只剩常规实现细节 | AI 自主研究与规划，不制造提问 |
| DEC-S5 | 清单部分回答、未答或否定推荐 | 按问题实际关闭；未决项仍阻塞依赖行为，独立调查继续 |
| DEC-S6 | Author 发现新需求歧义或恢复同范围会话 | 新问题回原 Clarify；已决定内容仍有效时不重复访谈 |
| DEC-S7 | UI 来源未绘制旧业务状态 | 先核对当前行为与要求，不能据此默默删除；真实冲突询问用户 |

## 5. 完整行为、条件与约束

本批承担整体全部要求，具体行为如下：

- 先检查仓库事实和既有约束，再按实际变更选择正常例子、关键边界与相关历史，找出不同解释的结果差异；不强制无关压力或矩阵。
- 所有未明确的需求选择必须由用户确认，轻度、可逆、惯例不能成为默认接受理由。服务器、平台等实际行为用合同、日志或实验查证，不能交用户猜测。
- 轻度且互不依赖的问题可以给出带逐项标识的推荐清单，明确允许接受或修正；有依赖或重大取舍时逐步询问。不能伪称独立条目不可分。
- 推荐不是决定；未答不算同意；部分答复只关闭已解决项。未决问题不实施依赖行为，独立调查可继续。保持现有每条 question_id 的生命周期与部分回答不关闭规则，不增加公共数据字段。
- 重大取舍提供可行选项、推荐理由与必要影响。既有约束内的纯实现细节由 AI 完成，不以技术未定要求用户提供代码，也不以技术细化掩盖需求选择。
- 回答更新所属需求、设计及验收；前任务阶段保留在会话。恢复复用有效决定，新增歧义仍处理。需求确认不替代独立副作用或完整规划激活。
- 原 owner 是唯一判断者；canonical、dogfood 与安装投影通过原分发同步；脚本只检查既定客观条件，不根据关键词判断语义。
- 增加教学例子与真实交互验证，分别报告结构、分发、实际 Agent 及未验证边界。

## 6. 本批验收、验证方式与未决项

DEC-AC1：通过原入口处理事实可查、需求清楚、轻度歧义及重大取舍请求，检查调查和提问是否匹配真实选择。

DEC-AC2：通过清单部分回答、接受、拒绝与未答序列，检查逐项关闭和依赖暂停，不允许自动默认。

DEC-AC3：检查后续规划是否使用实际回答而非原推荐；恢复复用决定，新歧义不被忽略。

DEC-AC4：UI 对齐例子必须保留没有要求改变的业务，技术命名不能掩盖需求决定。

DEC-AC5：定向 package、分发、dogfood drift、schema/JSON 及 diff 检查证明实际投影一致；不声称完整多平台升级矩阵。

DEC-AC6：实际 Agent 验证逐例记录观察与限制，不以结构测试或教学例子存在宣称提问有效。当前无待用户决定的需求问题，具体实现与执行入口由后续设计明确。
