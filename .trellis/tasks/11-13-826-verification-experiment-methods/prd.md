## 2. 背景与问题

R735 已定义正确预期、验证层级、证据复用、因果依据与实验停止。现有 eval runner 和原生采集可以提供执行事实。本批差额为可复用的项目验证入口建立及维护方法，以及真实 Agent 匿名对照的执行与判读方法。方法存在或结构检查通过不能证明真实行为通过。

## 3. 目标与非目标

交付可执行并能维护的项目验证方法，以及以真实行为比较 workflow/Skill 改动的方法。整体完成须覆盖下述全部要求和验收，不能用一个切片合并代替。

不引入 poteto-mode 总入口，不改 Task/Delivery 生命周期、现有公共 API 语义或权限边界。不增加固定设备 E2E、形式化证明、并发压力、故障注入、完整多平台矩阵和每任务必跑的实验门禁。不吞并 #747 的旅程方法范围。不建立重复功能账本、通用评分器或授权记录。

## 4. 真实调用方、场景与流程

| ID | 调用方、前置与动作 | 行为和可观察结果 |
| --- | --- | --- |
| S1 | 实施者需要验证项目行为，读取现有运行与测试设施 | 复用入口或补项目本地方法；按启动、就绪、真实操作、结果、清理、证据读取执行 |
| S2 | 后续实施者修改被覆盖的行为或代码入口 | 定位受影响验证，更新方法并重跑该路径，保留仍适用覆盖 |

| S4 | 项目或 Agent 环境依赖缺失，或执行发生失败 | 分别保留环境失败、未执行、目标行为失败和证据缺口，不能报告通过 |

## 5. 行为要求

### R1 可执行项目验证方法

读取真实启动方式、脚本、设施和调用入口。优先复用；覆盖不足时补项目本地方法。说明启动、就绪、真实操作、可观察结果、证据位置、清理。就绪必须达到所选旅程可用状态。只清理由本轮创建的实例和临时数据，证据在清理后仍可读取。操作遵守目标项目权限与外部副作用边界。关联 S1/S4、来源 R1。

### R2 实际证明与维护

方法实际跑通一条适用正常旅程。分别说明直接方法、替身和真实入口证据的覆盖层级。无 UI 使用 CLI、API 或库调用方，不强制设备。依赖缺失和执行失败如实报告。方法指出覆盖行为与代码入口；变化后定位、更新并重跑受影响路径，复用仍适用结果，不建重复功能账本。关联 S1/S2/S4、来源 R2。

### R3 匿名 Agent 对照

比较现行和候选方法使用同一任务材料及事前固定标准。执行 Agent 不接收评分标准、答案或优劣标签。评价者先读取匿名输出和真实工具记录，再由原 owner 判断改善、退化与未验证边界。工具只执行、采集和校验客观事实，不决定充分性。关联 S3、来源 R3。

### R4 实验事实与停止

优先复用既有 runner、原生入口和采集方式。保留支持复核的最小任务材料、实际方法版本、影响比较的环境差异和真实输出；禁止保存授权信息及敏感数据。环境失败、未执行与目标行为失败分别报告，失败不得静默替换。具体证据缺口需要新材料才补实验；小样本不推断普遍质量、耗时、token 改善。关联 S3/S4、来源 R4。

### R5 原职责内接入与分发

适用方法由原规划、实施、审核 owner 消费，不新增总控、固定审查轮次或实验门禁。沿 canonical/preset/tools owner 分发，保留用户定制和 Task/session。关联 S1–S4、来源 R5。

## 6. 约束与依赖

当前公共 I/O 和生命周期不变。新增能力是否独立 Skill 由 Delivery Author 根据完整闭环和最小 I/O 合同确定，不能预建只路由的 wrapper。共享知识由原 RDT/Architecture owner 维护，脚本不代替语义判断。受管副本沿工具维护 owner 同步，不能手工覆盖。

真实 Agent 对照依赖可用的原生执行入口；项目验证依赖可运行去敏项目。不可用时保留实际失败及未验证边界，推进独立工作，不弱化验收。源 lock、三平台投影和本地定制按现有安装合同处理，不推断外部业务采用。
