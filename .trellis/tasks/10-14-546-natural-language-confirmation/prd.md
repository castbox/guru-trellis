# 统一跨平台自然语言确认合同，避免结构化对话框与重复确认

## 当前来源与目标

Direct Source：[castbox/guru-trellis#546](https://github.com/castbox/guru-trellis/issues/546)，正文的“目标与范围”“验收”“不在范围”及[分发边界补充评论](https://github.com/castbox/guru-trellis/issues/546#issuecomment-6159835923)；当前 OPEN，updatedAt 为 2026-10-14T02:54:42Z。补充评论拥有本次分发验收调整；其余需求保留正文。任务只解决交互渠道和同动作重复确认，不评价 Cursor 旧流程。

默认用普通聊天展示操作、选择或澄清，尊重用户自然语言确认及交互偏好。提问工具的可用性不能改变确认语义。

## Requirements

- R546-01：唯一已展示操作接受“确认继续”等明确肯定回复，不要求按钮、身份复述或固定句式；已有精确请求的授权语义沿原合同承接。
- R546-02：普通聊天是默认渠道；用户偏好 prompt 时选择和澄清也用普通聊天。仅用户主动要求或平台上位约束强制要求时使用结构化渠道，仍遵守工具允许用途。
- R546-03：迟到、重复的按钮答案只对应其原问题；已确认或已完成动作不重复执行，不将其视为后续独立动作授权。不同时制造两种待确认入口，不持久化授权。
- R546-04：保留原副作用授权边界及 mapped transition/re-entry；新动作或实质变化按原合同确认，后置校验不新增交互门禁。
- R546-05：平台强制权限、沙箱、外部动作审批独立说明来源与动作，不承诺绕过；Agent 主动提问与平台审批分别评价。
- R546-06：公共 Markdown 合同唯一拥有交互语义，workflow/阶段/平台薄引用；当前交付 canonical 合同和平台投影源并做定向验证。旧 dogfood 同步延后原安装/迁移 owner 的合格完整迁移，不新增 wrapper、状态、DTO、局部安装器或脚本判断。

## Acceptance Criteria

- S546-01：无强制审批时普通“确认继续”承接唯一已展示计划，无 Agent 主动额外对话框。
- S546-02：当前精确动作已获明确请求/确认时直接承接；新的独立动作或实质变更仍走原确认。
- S546-03：文字先确认、按钮迟到、重复答案不重复执行、不授权下一动作。
- S546-04：默认及用户偏好 prompt 的选择/澄清走普通聊天；主动要求对话框仅按工具允许用途；未回答和预选不构成授权。
- S546-05：强制审批解释来源；后置校验和 mapped 接续不重复询问。
- S546-06：声明支持平台源投影语义一致；定向 source 与投影检查结果明确，旧 dogfood 漂移和未执行的 installed/reapply/drift 单列，不声明同步或通过；静态合同和真实客户端行为分开报告。

## 边界

不改客户端、上游 Trellis、授权拆分/合并、旧流程、需求同步、任务选型、runtime/schema/公共 API，不新增授权 artifact/checkpoint，不扩展完整 installer/release 矩阵。

基线 a07d03395373170f256cb187e3f1d317304f0449 的 canonical #531 候选与 installed legacy graph 有显式迁移边界。此任务沿完整 installed graph 规划执行，不执行 #531 升级、不手改 manifest、不新增局部安装器；旧 dogfood 同步按补充评论延后，不作为当前交付阻塞。投影策略由设计说明，未验证的客户端行为诚实保留。
