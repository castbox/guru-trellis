## 2. 整体与本批目标、非目标

整体目标是让协调者在单个动作待确认时继续推进独立工作。D1 从 DAG 公开入口交付已有委托、同轮继续观察、失效注册清理及已收敛 Issue 正文修订的可观察行为，并保留 R3 恢复边界。保持整图终止规则、并发槽位、失败传播、原步骤门禁和仓库写权限。隔离承载不创建真实 PR、不发布真实 Test、不修改真实 Issue，不新增持久状态、后台观察或审批流程。

## 3. 本批起点、前序结果、依赖与剩余责任

这是首个 Delivery，没有前序交付。固定起点为 `origin/main@8b92022d6cdf8f9debda09ed68602f1d137e3629`，交付和完成目标均为 `main`。该版本的隔离轨迹记录 A 的发布准备和直接确认条件、B 的 Test 状态，以及协调者在 B 仍运行时以 `progressing` 结束轮次。当前运行合同已经要求继续观察独立工作，问题出在原 Agent 在该授权交互中没有落实此规则。

依赖源包已有隔离 runner、真实 Codex CLI 和可控的 B 外部操作。传输探针已证明轮内消息可读；独立补证已观察到 B 结果释放、回读和推进。两项证据分开保留。候选验收尚未发生。八条失效注册的本机修复受本次单次授权，仅证明阻塞、原命令和同一节点的接续路径。Backend #1944 当前正文用于提取用例背景，不作为本 Task 的写权限来源。D1 后无计划中的下一切片；整体验收仍需实际候选证据、独立门禁、交付及 Task Completion。

## 4. 本批调用方、场景与流程

- **D1-SC1（R1）：**协调者收到原 owner 的待授权提案。若具体动作已被委托、仓库未要求用户本人确认，且原前置满足，则协调者明确指示原 owner 执行并回读结果。待授权字样本身不触发用户确认。
- **D1-SC2（R2）：**A 需用户本人确认或超出当前委托。独立 B 已有合法工作，其外部 Test 仍运行。协调者在当前轮发出 A 的具体确认请求。测试期间无用户回复；载体此时释放 B 结果。协调者仍在同一轮回读结果、决定 B 的下一步，并保持 A 及其依赖暂停。
- **D1-SC3（R3）：**如果会话实际中断，恢复原会话与原操作的事实，说明观察空档。指令或写入结果未知时，先查原操作，再决定是否需要后续动作。

- **D1-SC4（R4）：**当前节点原步骤因共享仓库失效注册受阻。协调者直接安排原执行者预览和逐项核对，仅移除目录不存在且无 Task 或运行操作需保留的准确清单。若命令会触及其他记录，先暂停并复查。回读仅有指定差额后恢复同一节点原步骤。
- **D1-SC5（R5）：**原需求审核已收敛，提案只是把权威和仓库证据已确定的内容写清。协调者核对隔离 Issue、完整待写正文和依据，安排原 owner 按正常写前核对与精确写回，回读后刷新受影响 Intake 和审核。真实选择、实质变化或用户本人要求仍按原确认路径。

## 5. 完整行为、条件与约束

DAG 判定由共享方法单写，DAG Skill 和本地合同引用它。权限判断由协调者完成。核对实际委托、目标仓库规则、具体动作和原 owner 前置。确认请求不能代替原 owner gate。A 的局部持有不改变 B 的权限或外部等待有效性。观察仍使用已有原生快照、游标和有界重查。当前仍有可合法推进的独立工作或有效有界等待时，不能仅为等待 A 结束本轮。

两项免单独确认不覆盖实际工作树、refs、提交、Task、运行操作或其他远端资源，也不用于目标、范围、验收或执行边界变化。正文已变化时先重新审核，不能覆盖并行修改；仅有标识不冲突不足以证明取舍已收敛。

如果没有剩余合法工作，原整图终止及安全停妥方法继续适用。如果宿主实际中断，走原恢复。任何恢复均不得重复已执行或结果未知的指令、PR 发布或其他写入。

## 6. 本批验收、验证方式与未决项

| 验收 | 同一公开入口的实际观察 |
| --- | --- |
| AC1 / D1-SC1 | 已委托场景出现原 owner 的精确提案和前置事实；实际记录协调者指令、原 owner 执行和协调者回读，且没有额外询问用户。 |
| AC2 / D1-SC2 | 现行和候选使用同一场景、同一判定口径和同一执行设置（`codex-cli 0.167.0`、`gpt-6-luna`、`high`）。记录确认请求、B 状态和结果可读时点、同轮回读及处置、轮次结束和 A 未执行。确认出现在最终回复时，使用结束前 B 的真实状态判定。若缺少前置、确认、轮次边界或 B 的可读时点，则记录证据不足。超时、进程退出或协调者自述不能单独定性。 |
| AC3 / D1-SC4 | 隔离节点从原 Task 创建等正常入口得到实际阻塞。真实协调者无额外确认地下达限定指令；记录 Git 预览、目录和 owner/操作核证、只移除列明注册的回读，以及同一节点原步骤复跑。现场八条不计候选通过。 |
| AC4 / D1-SC5 | 基于 #1944 取材的隔离 Issue，固定已收敛合同证据及精确修订。由真实协调者安排原 owner 做写前核对、精确写回、回读及 Intake 刷新。对仅不冲突且尚未收敛的选项保持原权限边界；真实 #1944 不写。 |
| R3 的兼容检查 | 核对原恢复规则和受影响的既有证据。只有候选实际改变恢复行为，才为受影响行为补验证。 |

AC1–AC4 均须由真实协调 Agent 从公开入口执行；载体既不替它判断，也不代表 App 原生调度。尚无待用户选择的行为。独立 Architecture 评估与实际候选测量仍未完成。
