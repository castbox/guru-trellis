# #901 原生观察与重算

## 输入和业务核验

固定输入是三个有序 UTF-8 JSON 对象，`text` 分别为`第一条`、`第二条`、`第三条`。自然任务是在只读的 `show` 子命令增加可选非负整数上限。运行 `python3 notes.py --store notes.json show` 时保留默认完整有序输出。给出合法上限时，输出至多指定数量的前缀。持久化数据保持原样。

两侧使用同一份输入和冻结口径。当地原始记录以隔离实验根的 `host/request.txt`、`host/criteria.md` 和 `host/native-<侧>-<轮次>.jsonl` 为定位。本文提供核验所需的最小观察，原始记录在本地保留。去敏复核材料用 X 和 Y，评价时未提供版本、发布对象或其他来源标识。评价结束后才揭示 X 为 .9（原轨迹 b），Y 为 .8（原轨迹 a）。

前置安装两侧首次错误为 `error: unknown option '-u'`。采用各 tag 文档允许的调用后构建和安装成功。模型首轮双侧 404 位于第 1 轮。第二轮 Discovery 在 `base_current.repository` 报 `stale_identity`，原因是本地 origin 无对应 GitHub 身份。认证读取对照退出 0。私有夹具使用两条已核验的基线 refs。原会话首个 resume 参数装配失败，调整参数位置后恢复。从已建立身份继续，保留首轮失败。
