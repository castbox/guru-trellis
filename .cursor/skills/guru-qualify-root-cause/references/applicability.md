# Root-cause applicability

The original caller reads this short contract before loading this qualifier's
`SKILL.md` or full contract. Invoke for a new or materially changed real
diagnosis, mitigation, root-cause repair or protection mechanism. Judge actual
behavior: an ordinary feature label does not remove incident or protection
behavior. A pure ordinary feature with neither behavior does not load this
qualifier or fill an incident questionnaire. Unknown cause alone does not
prevent bounded diagnosis or otherwise supported mitigation.

For the same mechanism, adopt a still-applicable conclusion available in the
conversation or an original owner gate that already needs it. A stage, caller,
HEAD or unrelated file change alone does not repeat qualification. Material
changes to scope, authority, mechanism, supported entry/consumer, conditions or causal
evidence refresh the affected judgment. Obtain a lost necessary conclusion from
its original owner or judge it again from live sources; never infer pass.

Before entry, the caller completes its current scenario and authority placement
judgments. When normal or solution is independently triggered, consume its real
outcome and resolve its nonpassing route first. When either is not triggered,
do not require or invent that qualifier's result to enter root. Root does not
repeat those owners' verdicts or invoke them recursively.

When invocation is needed, explicitly load the original Skill and complete
`contract.md`, submit the actual eligible nonempty candidate set and current
locators, and consume the original exit and unique consumer. Uncertain incident
or protection applicability with a real mechanism enters this owner; a missing
caller or object retains its entry gap. When not triggered, do not assemble
input, invoke an empty check or create a classified/skipped result. The caller
still reviews its current work and evidence. New invocations bind current facts;
adoption never replays an earlier envelope. No applicability artifact is written.
