# ADR-887-ISSUE-ENTRY-STREAMLINE 按目的进入 Issue 流程

状态 proposed。适用 #887 与当前 D1。固定前驱为 61da60132bd0f6b64ab8626ac3158093481cd21e。

## 决定

只建单与两类独立只读审核先进入各自原 owner。原 owner 读取实时材料并判断必要补查。直接建单复用一个执行和回读机制。确定性预备命令构造准确输入。直接入口在确定尚未写入时发生过期或草稿不匹配，由原 owner 单独承接刷新。若 provider 效果未知，则依据原尝试恢复同一对象。

独立只读审核完成后输出用户结论。原 issue_creation 和已进入的完整链保持原接口。明示开工时，正式 Issue 进入现有 Sync 与按缺口的 Readiness。

## 依据与影响

现行 ADR-ISSUE-REVIEW-INTAKE 的草稿和独立审核必经旧链约定在本范围内由新决定替代。该 ADR 的正式开工、已进入旧链、同对象恢复和评论责任继续适用。新决定沿用 ADR-005 与 ADR-009 规定的通用集成与 Issue 责任。与持续运行全链相比，直接入口减少实际交接。局部入口需要独立结果和消费者，才能隔离只读结论与正式 Gate。

原 Architecture owner 按实际实施和工程证据集成。有效目标正文及配对 RDT 与旧前驱的真实替代范围须能从 current 定位。
