# V638-07 去敏行为输入

本文只定义临时验证仓库的输入，不是 Guru Trellis 或任何业务服务的正式 authority。

不同能力双 Task 使用同一固定 Git B。查询 Task A 明确查询超时必须保留原错误来源。导出 Task B 明确导出任务完成不代表通知已发送。两者没有依赖。各 Task 只改命中完整知识单元，根入口与未命中单元保持。

共享单元双 Task 使用同一固定 B。原条件是有历史数据时不覆盖已有条件，缺来源返回原 repair。Task A 新增允许的只读查询入口；Task B 新增导出入口。最终组合保留 repair、有历史数据不覆盖和只读限制。未改 consumer 为查询调用方和导出调用方。

还要执行 no-change 和有变化但无需 Git 整合的路径。不创建空贡献、ADR 或空 commit，不 merge/rebase 追赶 SHA。当前样本只证明文档知识维护与真实 owner 流程，不声称生产服务部署或远端交付。
